# Diretrizes do Projeto — Portal SciBR

Este é um projeto público e de código aberto. O repositório é aberto para leitura e consulta.

## Contribuição de código

No momento **não aceitamos Pull Requests de código**. PRs sem alinhamento prévio serão fechadas sem merge. Para erros de funcionamento, abra uma Issue de bug.

## Envio de conteúdo

Artigos, podcasts, canais e projetos são enviados **exclusivamente pelo site**, na página "Enviar divulgação". Não envie PRs com arquivos de dados. Os envios passam por revisão antes de ficarem visíveis.

## Reportar conteúdo

Link quebrado, impróprio ou desinformação: abra uma Issue de **Reportar conteúdo**.

## Conduta

Mantenha respeito e cortesia. Problemas de segurança: veja [SECURITY.md](./SECURITY.md).
